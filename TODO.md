# План на будущее

## Панели дизайнера (как в WinForms)

- [x] Значки в Toolbox.
- [x] Свойства сверху, события снизу.
- [ ] Свойства по группам (внешний вид, расположение, поведение, данные), сортировка по алфавиту,
      описание выбранного свойства внизу панели.

## Свойства и события

- [x] Цвета, шрифт, выравнивание, подсказки, порядок Tab, только чтение и пароль.
- [x] События мыши, клавиатуры, фокуса, `closing` и `resize`.
- [ ] Семейство шрифта, курсор, поля и отступы, минимальный и максимальный размер,
      выбор цвета и шрифта окошком в IDE.

## Контролы

- [ ] Таблица (`DataGridView`), дерево, вкладки, `GroupBox`, числовое поле, ползунок,
      картинка, таймер.
- [ ] Свободный ввод в `ComboBox`, перенос по словам, выбор нескольких строк,
      перетаскивание полосы прокрутки.
- [x] Подменю.
- [ ] Значки и горячие клавиши меню, контекстное меню, панель инструментов,
      строка состояния.

## Дизайнер

- [ ] Выделение нескольких контролов, выравнивающие направляющие.
- [ ] Живой показ своих контролов.

## Проверки и платформы

- [ ] Запуск на настоящем Mac.

- [ ] Расширение Visual Studio: перетаскивание, клавиши, меню; подсказки по Rust —
