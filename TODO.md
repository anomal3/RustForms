# План на будущее

## Панели дизайнера (как в WinForms)

- [ ] **Значки в Toolbox**: маленький значок у каждого элемента, как в WinForms.
      Для RustRover, расширения Visual Studio (там сейчас стандартная заглушка) и отдельного дизайнера.
- [ ] **Свойства и события раздельно**: переключатель «Свойства» / «События» (кнопка с молнией),
      а не одна общая таблица. В RustRover и отдельном дизайнере; в Visual Studio события —
      отдельной вкладкой окна Properties.
- [ ] Свойства по группам (внешний вид, расположение, поведение, данные), сортировка по алфавиту,
      описание выбранного свойства внизу панели.

## Больше свойств и событий

Сейчас их заметно меньше, чем в WinForms.

- [ ] Свойства: шрифт и размер, цвета текста и фона у всех контролов, выравнивание текста,
      порядок Tab, подсказка (ToolTip), курсор, поля и отступы, минимальный и максимальный размер,
      только для чтения и символ пароля у `TextBox`.
- [ ] События: `mouse_enter`, `mouse_leave`, `mouse_down`, `mouse_up`, `mouse_move`, `double_click`,
      `key_down`, `key_up`, `got_focus`, `lost_focus`; у формы — `closing` (с отменой), `resize`.

## Контролы

- [ ] Таблица (`DataGridView`), дерево, вкладки, `GroupBox`, числовое поле, ползунок,
      картинка, таймер.
- [ ] Свободный ввод в `ComboBox`, перенос по словам, выбор нескольких строк,
      перетаскивание полосы прокрутки.
- [ ] Подменю, значки и горячие клавиши меню, контекстное меню, панель инструментов,
      строка состояния.

## Дизайнер

- [ ] Выделение нескольких контролов, выравнивающие направляющие.
- [ ] Живой показ своих контролов.

## Проверки и платформы

- [ ] Запуск на настоящем Mac.
- [ ] Системные диалоги на Linux.
- [ ] Расширение Visual Studio: перетаскивание, клавиши, меню; подсказки по Rust —
      после установки расширения для языка.

## Дальше, в сторону WPF
